# Clipboard

剪贴板历史管理器：常驻托盘，监听 Windows 剪贴板，把复制过的文本记成一份可置顶的历史，需要时一键取回。界面用 [GPUI](https://crates.io/crates/gpui) 0.2（Zed 的 Rust GPU 框架）绘制，纯 Rust，没有 webview。

## 功能

- **自动记录**：轮询剪贴板的序列号，变化时读取文本并入库。空白内容、超过 512 KB 的内容直接忽略；同样的文本重复复制只刷新时间、不新增条目。
- **一键取回**：点击条目（或选中后按 `Enter`）写回系统剪贴板；从工具内复制的内容不会再被记一遍（序列号 + 文本双重抑制）。
- **置顶与淘汰**：未置顶最多保留 50 条，超限淘汰最旧的那条；置顶条目无上限、不占额度、永不淘汰，按置顶时间排在前面。
- **常驻托盘**：`Ctrl+Shift+V` 唤出窗口（最小化状态下会先还原），托盘菜单提供「显示窗口 / 清空未置顶 / 退出」，左键点托盘图标同样唤出。
- **本地落盘**：历史存在 `%APPDATA%\AwesomeTools\clipboard\history.json`，先写临时文件再 `rename`，写一半被打断也不会损坏原文件；文件损坏或缺失时从空历史开始，不会卡启动。
- **键盘操作**：`↑`/`↓` 选择，`Enter` 复制，`Ctrl+P` 置顶 / 取消置顶，`Del` 删除，`Esc` 收起窗口。

## 架构

    src/
      model.rs     # Entry/Store：去重、置顶排序、超限淘汰、落盘（含单元测试）
      service.rs   # ClipboardService：剪贴板轮询、热键与托盘、保存防抖、开窗
      view.rs      # GPUI 视图：头部 / 列表 / 底部状态栏，键鼠事件转发
      platform.rs  # Windows 剪贴板序列号、全局热键、托盘图标
      icon.rs      # 图标几何（归一化坐标），托盘与 exe 图标共用
      format.rs    # 预览文本压缩、相对时间（含单元测试）
      main.rs      # Application::new().run：建 service、注册全局、开窗
    build.rs       # 由 src/icon.rs 生成多尺寸 .ico，编成 exe 的 ID 1 图标资源

两个关键设计：

1. **状态不属于窗口**。`ClipboardService` 是独立 entity，由全局 `ServiceHandle` 持有，自己跑一个 300 ms 的轮询任务；窗口只是它的一层渲染。
2. **用一个不显示的窗口撑住消息循环**。GPUI 在最后一个窗口关闭时直接 `PostQuitMessage`，进程就没了（托盘也跟着消失）。所以除了列表窗口，还开了一个 1×1、`show: false` 的 `KeepAlive` 窗口，它不渲染、不上任务栏，只负责让消息循环活到用户主动退出。

于是点 X 的行为是：列表窗口被销毁（显存按回去），进程留在托盘，热键 / 托盘「显示窗口」再按**关闭前的位置**重开一个新窗口。真正退出只有托盘菜单的「退出」。

图标全部由代码生成，仓库里不需要二进制图标资源：`src/icon.rs` 用归一化坐标画出剪贴板图形（4×4 超采样抗锯齿），托盘在运行时直接取 RGBA；`build.rs` 再把同一套几何渲染成 16/20/24/32/40/48/64/128 的多尺寸 `.ico`，生成 `.rc` 并编成 exe 里 ID 1 的图标资源。GPUI 创建窗口类时用 `LoadImageW(GetModuleHandleW(None), MAKEINTRESOURCE(1), IMAGE_ICON, ..)` 取图标，所以文件图标、任务栏、标题栏与 Alt+Tab 一次全对，窗口重建也不用重设。

## 构建

    cargo build --release

产物：`target/release/clipboard.exe`（release profile 已开 LTO、`opt-level = "s"`、strip）。

## 校验

    cargo test
    cargo clippy --all-targets

`cargo test` 覆盖 store 的去重 / 排序 / 淘汰 / 置顶 / 清理 / 落盘往返 / 坏文件回退，以及文本压缩与相对时间格式化。UI、热键、托盘这些需要真实桌面交互的部分没有自动化测试，只能手动验证：

1. 复制几段文本，窗口里应逐条出现，重复复制同一段不会新增。
2. 在工具里点击某条 → 到别处 `Ctrl+V` 应粘出该条内容，且历史里不会多出一条；标题栏左上角与任务栏都应是剪贴板图标，而不是默认控制台图标。
3. 置顶一条，再复制超过 50 条，置顶那条仍在，最早的未置顶记录被淘汰。
4. 点 X 关掉窗口：托盘图标应仍然在，进程不退出；再用 `Ctrl+Shift+V` 或托盘「显示窗口」唤出，窗口回到关闭前的位置，历史还在。
5. 退出后重开，历史与置顶状态保留。

## 已知限制

- 只处理文本；图片、文件列表（资源管理器复制文件产生的路径列表）不记录。
- 热键固定 `Ctrl+Shift+V`，如果被别的程序占用，会在标题栏下方显示提示，此时仍可用托盘图标。
- 只在 Windows 上验证过；剪贴板序列号与托盘走 Windows API，其它平台的全局热键 / 托盘行为未测试。
